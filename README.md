# 🧾 Mini ERP Inventory Billing System

A simple Flask + SQLite based ERP system that manages:
- Products  
- Customers  
- Bills  
- Revenue Dashboard  

## Features
✅ Add customers  
✅ Add products  
✅ Generate bills  
✅ View dashboard  

## Tech Stack
- Python (Flask)
- SQLite
- HTML (Optional UI)
